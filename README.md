# SPIN Workshop Website

Website for the 1st Workshop on Structured Physical Intelligence (SPIN) at CoRL 2026.

Plain static HTML and CSS — no build step, no framework, no JavaScript. `index.html`
and `styles.css` sit at the repository root alongside `assets/`, so the repository can be
served directly by GitHub Pages.

## Local preview

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>. Opening `index.html` in a browser directly works too.
